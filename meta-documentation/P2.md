## 0. What you are building, in one paragraph

A consent artefact is full of facts (what data, why, who-else-gets-it, for how long, how often). Your
**summarizer** turns those facts into one short, plain-English paragraph a normal person can read. But an
AI summary can silently **drop a fact** ("forgot to mention it's shared with credit bureaus") or **invent
one** ("says valid 5 years when it's 2"). So your second, more important piece is a **faithfulness audit**:
a program that checks the summary against the original facts and reports *"did the summary keep every fact,
and did it add anything that wasn't there?"* **That audit is the research contribution** — anyone can run
T5; almost nobody measures whether the plain-English summary is actually truthful.

*Analogy: the summarizer is a translator giving you the gist of a contract; the faithfulness audit is a
second lawyer checking the translator didn't quietly leave out a clause or make one up.*

## 1. Why this matters (say this in the paper)

> ⚠ **Corrected after the systematic search (see [`RELATED_WORK.md`](RELATED_WORK.md), D28).** An earlier
> version of this guide said "almost nobody measures whether the summary is truthful." **That is wrong.**
> Entity-level faithfulness metrics are canonical (arXiv:2102.09130), and **EROS** (arXiv:2403.00141)
> already does entity-controlled summarization *of privacy policies*. Do **not** claim the metric as novel.

- The summarizer is not novel, and **neither is the faithfulness metric**. What you contribute is its
  **application**: EROS uses entities to *control generation*; you use entity preservation as a *post-hoc
  audit of disclosure fidelity* in the Indian AA consent domain — against a regulatory obligation that
  mandates informing the user but never verifies that the informing was accurate.
- Your headline number is still **faithfulness coverage**, not ROUGE. Cite arXiv:2102.09130 as the metric's
  source and EROS as the nearest neighbour. (Locked in DECISIONS D4 + D28 + the plan's Part B4.)
- Standard summary scores (ROUGE, BERTScore) are **inflated** here because AA consent language is
  boilerplate (every doc says similar things). So you must also report a **boilerplate baseline** to show
  how much of the score is trivial. (Plan B4.)

## 4. The data problem (read this before coding) — Option A: summarize the 3 PROSE facts

**What the neural summarizer summarizes:** the **3 prose facts only** — DATA_TYPE, PURPOSE, THIRD_PARTY
(the things P1's NER extracts). It does **NOT** summarize frequency/duration/recipient. Why: per
**DECISIONS D27**, the real scraped policy docs contain the 3 prose facts but **not** the structured 3
(those live only in a consent-artefact JSON the prose docs aren't paired with). So the summarizer is
trained and tested on the same 3-fact shape. The structured 3, when a consent artefact *is* present, are
**appended by a one-line template downstream** (`"…valid until X, fetched Y times per Z"`) — that's the
split-by-source design, and it keeps the neural task honest and its input identical in train and test.

The AI's **input is always the linearized 3 facts** — one flat line like
`"DATA_TYPES: …. PURPOSES: …. THIRD_PARTIES: …."` — in BOTH training and testing. (If you train on one
input shape and test on another, the model fails. Never feed it raw policy prose at test time — feed it
the same flattened 3 facts it trained on.)

**Two data sources for the two halves:**

1. **Training set = SYNTHETIC 3-fact records → template summaries (cheap, many).** A small generator picks
   random realistic data-types / purposes / third-parties from an AA-domain vocab and writes a template
   summary. **Why synthetic and not the real docs:** you cannot fine-tune T5 on ~10 examples — it needs
   dozens to learn the summary *style*. Synthetic gives the volume. *(A template alone could do the job —
   keep it as a baseline, not the product; the research is the neural model + faithfulness.)*

2. **Gold test set = the FIRST 10 REAL AA docs, with summaries HAND-WRITTEN by P1/P4.** Your honest
   yardstick and the number you report (Plan B4: "test summaries human-authored"). Uses P1/P4's work
   directly — see the hand-off below.

   - **Input (facts)** for each real doc = P1's **gold NER entities** (DATA_TYPE/PURPOSE/THIRD_PARTY),
     linearized the same way as the training inputs.
   - **Reference (answer)** = the **3–5 plain-English sentences P1/P4 write** after annotating each doc.
   - **Bonus:** because you have gold entities for these 10 docs, the faithfulness audit (§7) checks the
     summary against a **real answer key**, not just synthetic facts — a stronger result.

> **The P1/P4 hand-off (a tiny, near-free task).** P1 and P4 already read each AA doc fully to annotate it.
> Ask them, for the first **10** docs, to also write a short **3–5 sentence** plain-English summary (what
> data, why, who else). ~5 min per doc. They give you two things per doc: their **annotation** (→ your
> input facts: data-types/purposes/third-parties) and their **handwritten summary** (→ your reference).
> This is your entire gold test set — small but reportable; state the size (n=10) as a limitation.

> Keep train and test **completely separate** — the model trains only on synthetic; it is graded only on
> the 10 real docs it never saw.

### Step 4a — Build the datasets: `summ/make_dataset.py` (new file)

`--split train` synthesizes the training file directly (no other inputs). `--split test` reads the P1/P4
hand-off `data/summ/gold_refs.jsonl` (Step 4b) and turns it into the test file.

```python
# src/consentledger/summ/make_dataset.py
"""Build the summarizer datasets (Option A: summarize the 3 PROSE facts).

Neural task: (DATA_TYPE + PURPOSE + THIRD_PARTY) -> plain-English summary. The structured 3 fields
(frequency/duration/recipient) are NOT here — they're template-appended downstream when a consent artefact
is present (split-by-source, D27).

TRAIN: synthetic 3-fact records -> template summary (many, cheap).
TEST : the 10 real docs -> (gold 3 facts from P1's NER, P1/P4 handwritten summary), read from
       data/summ/gold_refs.jsonl; each line = {"id","data_types","purposes","third_parties","reference"}.

Usage:
    python -m consentledger.summ.make_dataset --split train --out data/summ/train.jsonl --n 80
    python -m consentledger.summ.make_dataset --split test  --out data/summ/test.jsonl
"""
from __future__ import annotations
import argparse, json, random
from pathlib import Path

ROOT = Path(__file__).resolve().parents[3]
GOLD = ROOT / "data" / "summ" / "gold_refs.jsonl"      # hand-off from P1/P4 (see Step 4b)

# small AA-domain vocab, just to synthesize training variety
DATA_TYPES = ["bank statements", "mutual fund holdings", "PAN", "salary details", "credit card statements",
              "insurance policies", "savings account balance", "loan repayment history", "GST returns"]
PURPOSES = ["loan eligibility assessment", "credit underwriting", "wealth management",
            "spending analysis", "account monitoring for collections", "personal finance management"]
THIRD_PARTIES = ["credit bureaus", "affiliates", "service providers", "group companies", "lending partners"]

def linearize(dts, purps, tps) -> str:
    """The 3 prose facts as one flat string T5 reads (identical shape in train and test)."""
    return (f"DATA_TYPES: {'; '.join(dts)}. "
            f"PURPOSES: {'; '.join(purps)}. "
            f"THIRD_PARTIES: {'; '.join(tps) if tps else 'none'}.")

def template_summary(dts, purps, tps) -> str:
    """Deterministic plain-English summary — training target + boilerplate baseline."""
    s = f"This consent lets the requesting institution access your {', '.join(dts)} for {', '.join(purps)}."
    if tps:
        s += f" Your data may also be shared with {', '.join(tps)}."
    return s

def build_train(out: Path, n: int, seed: int = 42) -> int:
    rng = random.Random(seed)
    with out.open("w", encoding="utf-8") as fh:
        for i in range(n):
            dts = rng.sample(DATA_TYPES, rng.randint(1, 4))
            purps = rng.sample(PURPOSES, rng.randint(1, 2))
            tps = rng.sample(THIRD_PARTIES, rng.randint(0, 2))
            fh.write(json.dumps({"id": f"syn{i:03d}", "source": linearize(dts, purps, tps),
                                 "reference": template_summary(dts, purps, tps),
                                 "cd": {"data_types": dts, "purposes": purps, "third_parties": tps}}) + "\n")
    return n

def build_test(out: Path) -> int:
    """The 10 real docs: linearize the GOLD 3 facts P1/P4 supply, keep their HANDWRITTEN summary."""
    if not GOLD.exists():
        raise SystemExit(f"missing {GOLD} — P1/P4 must supply gold_refs.jsonl first (see Step 4b).")
    rows = [json.loads(l) for l in GOLD.read_text(encoding="utf-8").splitlines() if l.strip()]
    with out.open("w", encoding="utf-8") as fh:
        for r in rows:
            dts, purps, tps = r.get("data_types", []), r.get("purposes", []), r.get("third_parties", [])
            fh.write(json.dumps({"id": r["id"], "source": linearize(dts, purps, tps),
                                 "reference": r["reference"],
                                 "cd": {"data_types": dts, "purposes": purps, "third_parties": tps}}) + "\n")
    return len(rows)

def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--split", choices=["train", "test"], required=True)
    ap.add_argument("--out", type=Path, required=True)
    ap.add_argument("--n", type=int, default=80, help="synthetic training rows")
    args = ap.parse_args()
    args.out.parent.mkdir(parents=True, exist_ok=True)
    n = build_train(args.out, args.n) if args.split == "train" else build_test(args.out)
    print(f"wrote {args.out} ({n} rows)")

def _selfcheck() -> None:
    assert "bank statements" in linearize(["bank statements"], ["loan eligibility assessment"], [])
    s = template_summary(["PAN"], ["credit underwriting"], ["credit bureaus"])
    assert "PAN" in s and "credit bureaus" in s
    assert "none" in linearize(["PAN"], ["x"], [])       # empty third-parties -> 'none'
    print("selfcheck OK")

if __name__ == "__main__":
    import sys
    (_selfcheck if "--selfcheck" in sys.argv else main)()
```

## 5. Load the dataset: fill in `summ/dataset.py`

```python
# src/consentledger/summ/dataset.py
"""Load the JSONL (source, reference) pairs and tokenize for a T5 seq2seq model."""
from __future__ import annotations
import json
from pathlib import Path
from datasets import Dataset

def read_jsonl(path: str | Path) -> Dataset:
    rows = [json.loads(l) for l in Path(path).read_text(encoding="utf-8").splitlines() if l.strip()]
    return Dataset.from_list(rows)

def build(train_path, test_path, tokenizer, prefix, max_src=512, max_tgt=128):
    def tok(batch):
        model_in = tokenizer([prefix + s for s in batch["source"]],
                             max_length=max_src, truncation=True)
        labels = tokenizer(text_target=batch["reference"], max_length=max_tgt, truncation=True)
        model_in["labels"] = labels["input_ids"]
        return model_in
    tr, te = read_jsonl(train_path), read_jsonl(test_path)
    keep = ["input_ids", "attention_mask", "labels"]
    return (tr.map(tok, batched=True, remove_columns=[c for c in tr.column_names if c not in keep]),
            te.map(tok, batched=True, remove_columns=[c for c in te.column_names if c not in keep]))
```

```python
# src/consentledger/summ/train.py
"""Fine-tune T5/Flan-T5 with Seq2SeqTrainer. Usage:
    python -m consentledger.summ.train --config configs/summ_t5small.yaml
    python -m consentledger.summ.train --config configs/summ_t5small.yaml --smoke   # tiny, fast sanity run
"""
from __future__ import annotations
import argparse, json, yaml
from pathlib import Path
from transformers import (AutoTokenizer, AutoModelForSeq2SeqLM, DataCollatorForSeq2Seq,
                          Seq2SeqTrainer, Seq2SeqTrainingArguments)
from consentledger.summ.dataset import build

ROOT = Path(__file__).resolve().parents[3]

def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--config", required=True)
    ap.add_argument("--smoke", action="store_true")
    args = ap.parse_args()
    cfg = yaml.safe_load(Path(args.config).read_text())

    model_name = cfg["model_name"]
    if model_name == "t5-small":     # resolve bare id (plan A8) to the canonical Hub id
        model_name = "google-t5/t5-small"
    tok = AutoTokenizer.from_pretrained(model_name)
    model = AutoModelForSeq2SeqLM.from_pretrained(model_name)

    train_ds, eval_ds = build(ROOT/"data/summ/train.jsonl", ROOT/"data/summ/test.jsonl",
                              tok, cfg["source_prefix"], cfg["max_source_length"], cfg["max_target_length"])
    if args.smoke:
        train_ds, eval_ds = train_ds.select(range(min(8, len(train_ds)))), eval_ds.select(range(min(4, len(eval_ds))))

    out = Path(cfg["output_dir"] + ("_smoke" if args.smoke else ""))
    targs = Seq2SeqTrainingArguments(
        output_dir=str(out), seed=cfg["seed"],
        learning_rate=float(cfg["learning_rate"]),
        per_device_train_batch_size=cfg["per_device_train_batch_size"],
        num_train_epochs=1 if args.smoke else cfg["num_train_epochs"],
        predict_with_generate=True, generation_num_beams=cfg["num_beams"],
        eval_strategy="epoch", save_strategy="epoch", load_best_model_at_end=True,
        bf16=True, report_to="none",
    )
    trainer = Seq2SeqTrainer(model=model, args=targs, train_dataset=train_ds, eval_dataset=eval_ds,
                             data_collator=DataCollatorForSeq2Seq(tok, model=model), tokenizer=tok)
    trainer.train()
    trainer.save_model(str(out))
    tok.save_pretrained(str(out))
    (out/"run_meta.json").write_text(json.dumps({"model_name": model_name, "config": args.config,
                                                 "seed": cfg["seed"]}, indent=2))
    print(f"saved summarizer -> {out}")

if __name__ == "__main__":
    main()
```

## 7. THE MAIN CONTRIBUTION — Faithfulness audit: `summ/faithfulness.py` (new file)

This is the piece you should spend the most care on. It answers two questions for each summary:
- **Coverage (recall):** of the facts that were in the input, how many appear in the summary? *(dropped
  facts = low coverage.)*
- **Hallucination (precision):** of the facts the summary states, how many were actually in the input?
  *(invented facts = high hallucination.)*

```python
# src/consentledger/summ/faithfulness.py
"""Entity-preservation faithfulness of a summary vs its source facts (Option A: the 3 PROSE facts).

Coverage      = |input facts found in summary| / |input facts|          (did we drop anything?)
Hallucination = |summary facts NOT in input|   / |summary facts|        (did we invent anything?)

The 'facts' are the 3 prose facts (data_types / purposes / third_parties) that the summarizer is
responsible for — the same `cd` shape produced by make_dataset.py. Detect a fact in the summary two ways:
  1. cheap normalized substring match;
  2. if P1's NER model is available (ner_fn), also match its entities from the summary (catches paraphrase).
Structured fields (frequency/duration/recipient) are appended by template downstream and are NOT scored
here (D27, split-by-source). Pass ner_fn=None until P1's model exists — substring matching still works.
"""
from __future__ import annotations
import re

FACT_KEYS = ("data_types", "purposes", "third_parties")   # kind label = key minus trailing 's'

def _norm(s: str) -> str:
    return re.sub(r"\s+", " ", str(s).lower()).strip()

def input_facts(cd: dict) -> set[str]:
    """The atomic facts a faithful summary must preserve: the 3 prose facts."""
    facts = set()
    for key in FACT_KEYS:
        kind = key[:-1]                       # data_types -> data_type, etc.
        for v in cd.get(key, []):
            if v:
                facts.add(f"{kind}:{_norm(v)}")
    return facts

def fact_in_summary(fact: str, summary: str, ner_fn=None) -> bool:
    _, val = fact.split(":", 1)
    s = _norm(summary)
    if val in s:                              # cheap exact/substring hit
        return True
    if ner_fn:                                # let P1's NER catch paraphrases in the summary
        ents = {_norm(e) for e in ner_fn(summary)}
        return any(val in e or e in val for e in ents)
    return False

def score_one(cd: dict, summary: str, ner_fn=None) -> dict:
    fin = input_facts(cd)
    kept = {f for f in fin if fact_in_summary(f, summary, ner_fn)}
    coverage = len(kept) / len(fin) if fin else 1.0
    halluc = 0.0
    if ner_fn:
        summ_ents = {_norm(e) for e in ner_fn(summary)}
        src_vals = {f.split(":", 1)[1] for f in fin}
        invented = {e for e in summ_ents if not any(e in v or v in e for v in src_vals)}
        halluc = len(invented) / len(summ_ents) if summ_ents else 0.0
    return {"coverage": round(coverage, 4), "hallucination": round(halluc, 4),
            "n_facts": len(fin), "n_kept": len(kept), "dropped": sorted(fin - kept)}

def _selfcheck() -> None:
    cd = {"data_types": ["bank statements", "mutual fund holdings"],
          "purposes": ["loan eligibility assessment"], "third_parties": ["credit bureaus"]}
    good = ("This consent lets the lender access your bank statements and mutual fund holdings for "
            "loan eligibility assessment. Data may be shared with credit bureaus.")
    bad  = "Access to your data for some purpose."
    assert score_one(cd, good)["coverage"] > 0.8
    assert score_one(cd, bad)["coverage"] < 0.5
    print("selfcheck OK")

if __name__ == "__main__":
    import sys
    if "--selfcheck" in sys.argv:
        _selfcheck()
```

## 8. Standard metrics + boilerplate baseline: fill in `summ/evaluate.py`

```python
# src/consentledger/summ/evaluate.py  (key parts)
"""ROUGE + BERTScore of predictions vs references, WITH a boilerplate baseline, + faithfulness.
Usage: python -m consentledger.summ.evaluate --pred data/summ/preds.jsonl --out results/summ/metrics.json
"""
import json, argparse
from pathlib import Path
import evaluate as hf_evaluate
from consentledger.summ.faithfulness import score_one   # reuse

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--pred", required=True, help="jsonl with {id, source, reference, prediction, cd}")
    ap.add_argument("--out", required=True)
    a = ap.parse_args()
    rows = [json.loads(l) for l in Path(a.pred).read_text(encoding="utf-8").splitlines() if l.strip()]

    rouge, bert = hf_evaluate.load("rouge"), hf_evaluate.load("bertscore")
    preds  = [r["prediction"] for r in rows]
    refs   = [r["reference"]  for r in rows]
    srcs   = [r["source"]     for r in rows]          # boilerplate baseline = the raw source text
    R  = rouge.compute(predictions=preds, references=refs)
    Rb = rouge.compute(predictions=srcs,  references=refs)   # <- how much score is trivial overlap
    B  = bert.compute(predictions=preds, references=refs, lang="en")

    faith = [score_one(r["cd"], r["prediction"]) for r in rows if "cd" in r]
    cov = sum(f["coverage"] for f in faith)/len(faith) if faith else None
    hal = sum(f["hallucination"] for f in faith)/len(faith) if faith else None

    out = {"rougeL": R["rougeL"], "rougeL_boilerplate_baseline": Rb["rougeL"],
           "bertscore_f1": sum(B["f1"])/len(B["f1"]),
           "faithfulness_coverage": cov, "faithfulness_hallucination": hal, "n": len(rows)}
    Path(a.out).parent.mkdir(parents=True, exist_ok=True)
    Path(a.out).write_text(json.dumps(out, indent=2))
    print(json.dumps(out, indent=2))
    print("HEADLINE = faithfulness_coverage (not ROUGE). ROUGE minus its boilerplate baseline = real lift.")

if __name__ == "__main__":
    main()
```

## 11. If you get stuck / common issues

- **T5 needs `sentencepiece`** — already installed; if it complains, `pip install sentencepiece==0.2.0`.
- **Bare `t5-small` id fails on the Hub** → the code already rewrites it to `google-t5/t5-small`.
- **BERTScore downloads a big model on first run** — that's normal; pin its version for the paper.
- **Summaries look repetitive** → the configs already set `no_repeat_ngram_size` and beams; also try more
  training epochs (early stopping is on via `load_best_model_at_end`).
- **Faithfulness coverage is low even for good summaries** → your string matching is too strict; loosen
  the date/number matching or plug in the NER `ner_fn` for paraphrase-tolerant matching.
