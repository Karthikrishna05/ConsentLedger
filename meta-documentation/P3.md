# P3 — Smart Contract: On-chain Consent Registry (implementation guide)

Written in plain language with concrete steps, file paths, commands, and full code, so **you can implement
this part even if you've never written Solidity or touched a blockchain before.**

Where this fits: pipeline step **5** in [`FLOW.md`](FLOW.md) — after the facts are extracted and
summarized, you record a **tamper-proof fingerprint** of the consent on a public blockchain, so anyone can
later verify the consent existed and was not altered. Design rationale: [`DECISIONS.md`](DECISIONS.md) and
the plan's Part D4.

## 0. What you are building, in one paragraph

You write a small **smart contract** — a program that lives on the Ethereum test network (Sepolia) and
that nobody can secretly change. It stores, for each consent, a **hash** (a short fingerprint) of the
consent's facts, plus its status (granted / revoked) and expiry. Later, anyone can present a consent and
ask the contract *"is this the exact consent that was recorded, and is it still valid?"* If even one
character of the consent was changed, the fingerprint won't match and the contract says **no**. **No
personal data ever goes on-chain — only the hash.**

*Analogy: instead of putting your signed contract in a public glass case (everyone reads your private
details), you put a tamper-evident wax seal of it in the case. The seal proves the contract is genuine and
unchanged, but reveals none of its contents.*

## 1. Why this matters (say this in the paper)

- **Tamper-evidence:** a hash on an immutable ledger means a consent record cannot be quietly back-dated,
  edited, or denied. That's the trust property the AA framework wants and that a normal database can't
  prove.
- **Privacy by design:** you store **hashes, not strings** — no data types, no names, no purposes on-chain.
  (DECISIONS: hashes-not-strings.)
- **Honest scope:** you demonstrate a *reference registry*, not a production system. State two limits
  openly: (a) a **malicious AA** that lies before hashing is out of scope — the chain proves the record is
  unchanged, not that it was honest at creation (plan: "malicious-AA disclosed, not solved"); (b) expiry is
  **lazy** — the contract can't run a timer, so it checks expiry only when someone asks (see §4).

## 2. What you need from others — and what you can start TODAY

## 3. Key ideas before you touch code (5-minute read)

- **Hash (keccak256):** a function that turns any text into a fixed 32-byte fingerprint. Same input →
  same fingerprint; change one character → completely different fingerprint. It's one-way (you can't get
  the text back from the hash), which is why it's privacy-safe.
- **Canonicalization:** before hashing, you must turn the artefact into **one exact, repeatable string**
  (same key order, no random spacing), so the Python side and anyone re-checking later get the *identical*
  hash. We use `json.dumps(obj, sort_keys=True, separators=(",",":"))`.
- **Wallet / private key:** to write to the chain you sign transactions with a wallet's private key.
  **Use a brand-new throwaway wallet with only free test-ETH — NEVER a real wallet or real funds.**
  (DECISIONS: Sepolia throwaway test wallet only.)
- **Gas:** writes cost "gas", paid in test-ETH you get free from a faucet. Reads are free.
- **State-changing vs view:** a function that changes stored data ("write", costs gas, leaves a permanent
  record/event) vs a "view" that only reads (free). Your **security test must target the state-changing
  path**, because that's the one that leaves the audit trail (plan requirement).

## 4. The contract: `contracts/contracts/ConsentRegistry.sol`

The `contracts/` folder already has a `contracts/ / scripts/ / test/` layout. Put this file at
`contracts/contracts/ConsentRegistry.sol`:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

/// @title ConsentRegistry — tamper-evident, privacy-preserving consent records.
/// @notice Stores ONLY a keccak256 hash of each consent artefact (no personal data on-chain).
contract ConsentRegistry {
    // The lifecycle of a consent. NONE = never created.
    enum Status { NONE, CREATED, GRANTED, REVOKED }

    struct Consent {
        bytes32 artefactHash;   // keccak256 of the canonical consent artefact (a fingerprint, not data)
        address owner;          // who created it (the AA/FIU acting for the user)
        uint64  expiry;         // unix seconds; after this the consent is treated as expired
        uint256 nonce;          // caller-supplied number that makes each consentId unique (anti-replay)
        Status  status;
    }

    mapping(bytes32 => Consent) public consents;   // consentId => record

    event ConsentCreated(bytes32 indexed consentId, bytes32 artefactHash, uint64 expiry, uint256 nonce);
    event ConsentGranted(bytes32 indexed consentId);
    event ConsentRevoked(bytes32 indexed consentId);
    // The audit event: emitted every time someone verifies an access attempt (the state-changing path).
    event AccessRecorded(bytes32 indexed consentId, bytes32 presentedHash, bool valid);

    /// Step 1 of the lifecycle: create the record with its fingerprint. Reverts if the id already exists.
    function createConsent(bytes32 consentId, bytes32 artefactHash, uint64 expiry, uint256 nonce) external {
        require(consents[consentId].status == Status.NONE, "consent exists");
        consents[consentId] = Consent(artefactHash, msg.sender, expiry, nonce, Status.CREATED);
        emit ConsentCreated(consentId, artefactHash, expiry, nonce);
    }

    /// Step 2: the user (via the owner) grants it. Only the owner, only from CREATED.
    function grantConsent(bytes32 consentId) external {
        Consent storage c = consents[consentId];
        require(c.status == Status.CREATED, "not in created state");
        require(c.owner == msg.sender, "not owner");
        c.status = Status.GRANTED;
        emit ConsentGranted(consentId);
    }

    /// Revoke at any time. Only the owner, only if currently GRANTED.
    function revokeConsent(bytes32 consentId) external {
        Consent storage c = consents[consentId];
        require(c.status == Status.GRANTED, "not granted");
        require(c.owner == msg.sender, "not owner");
        c.status = Status.REVOKED;
        emit ConsentRevoked(consentId);
    }

    /// STATE-CHANGING verification path — this is what the adversarial test targets.
    /// Records (as an event) whether the presented artefact matches AND the consent is live & unexpired.
    function recordAccess(bytes32 consentId, bytes32 presentedHash) external returns (bool valid) {
        Consent storage c = consents[consentId];
        valid = (
            c.status == Status.GRANTED &&
            block.timestamp <= c.expiry &&      // lazy expiry: evaluated here, at access time
            c.artefactHash == presentedHash     // tamper check: fingerprints must match exactly
        );
        emit AccessRecorded(consentId, presentedHash, valid);
    }

    /// Free read-only version of the same check (no event, no gas). Handy for the pipeline/demo.
    function isValid(bytes32 consentId, bytes32 presentedHash) external view returns (bool) {
        Consent storage c = consents[consentId];
        return c.status == Status.GRANTED && block.timestamp <= c.expiry && c.artefactHash == presentedHash;
    }
}
```

**Why it's built this way (each maps to a locked decision):**
- `bytes32 artefactHash` only → *hashes-not-strings* (no personal data on-chain).
- `enum Status` + `createConsent`/`grantConsent`/`revokeConsent` → the *enum lifecycle* the `chain/`
  stubs expect (`register_consent.py`: "createConsent + grantConsent").
- `nonce` in the id derivation → *nonce-based consent IDs* (prevents two consents colliding / replay).
- `recordAccess` emits an event → the *state-changing audit path* your security test attacks.
- `block.timestamp <= c.expiry` inside the check → *lazy expiry, stated honestly*.

Deploying needs the compiled contract. The easiest, no-toolchain way:

3. **Compile:** left tab "Solidity Compiler" → pick compiler `0.8.20+` → **Compile**.

   Remix to your Sepolia wallet) → confirm MetaMask is on Sepolia → click **Deploy** → approve the
   MetaMask popup (spends a little test-ETH).

   `CONSENT_REGISTRY_ADDRESS`.
6. In Remix, also copy the **ABI** (Solidity Compiler tab → "ABI" button) and save it to
   `contracts/ConsentRegistry.abi.json` in the repo. (The ABI is the "menu" of functions Python needs to

## 7. Talk to the contract from Python: fill in `chain/web3_client.py`

`web3.py` (v6) is already pinned in `requirements.txt`. This module connects and exposes the contract.

```python
# src/consentledger/chain/web3_client.py
"""web3.py v6 connection to Sepolia + a loaded ConsentRegistry contract object.

Reads SEPOLIA_RPC_URL, TEST_WALLET_PRIVATE_KEY, CONSENT_REGISTRY_ADDRESS from .env.
"""
from __future__ import annotations
import json, os
from pathlib import Path
from dotenv import load_dotenv
from web3 import Web3

ROOT = Path(__file__).resolve().parents[3]
load_dotenv(ROOT / ".env")

def get_web3() -> Web3:
    w3 = Web3(Web3.HTTPProvider(os.environ["SEPOLIA_RPC_URL"]))
    assert w3.is_connected(), "cannot reach Sepolia RPC — check SEPOLIA_RPC_URL"
    return w3

def get_account(w3: Web3):
    return w3.eth.account.from_key(os.environ["TEST_WALLET_PRIVATE_KEY"])

def get_contract(w3: Web3):
    abi = json.loads((ROOT / "contracts" / "ConsentRegistry.abi.json").read_text())
    return w3.eth.contract(address=Web3.to_checksum_address(os.environ["CONSENT_REGISTRY_ADDRESS"]), abi=abi)

def send(w3: Web3, acct, fn):
    """Sign + send a state-changing call; wait for the receipt. (web3 v6 syntax.)"""
    tx = fn.build_transaction({
        "from": acct.address,
        "nonce": w3.eth.get_transaction_count(acct.address),
        "chainId": w3.eth.chain_id,
    })
    signed = acct.sign_transaction(tx)
    h = w3.eth.send_raw_transaction(signed.raw_transaction)   # v6: .raw_transaction
    return w3.eth.wait_for_transaction_receipt(h)
```

## 8. Hash + register a consent: fill in `chain/register_consent.py`

```python
# src/consentledger/chain/register_consent.py
"""canonicalize a consent artefact -> keccak256 -> createConsent + grantConsent on-chain.

Usage:
    python -m consentledger.chain.register_consent --artefact data/aa/consent_artefacts/real_onetime_loan_application.json
"""
from __future__ import annotations
import argparse, json, time
from datetime import datetime, timezone
from pathlib import Path
from web3 import Web3
from consentledger.chain.web3_client import get_web3, get_account, get_contract, send

def canonical_bytes(artefact: dict) -> bytes:
    """ONE exact, repeatable byte-string for the artefact (sorted keys, no spaces)."""
    clean = {k: v for k, v in artefact.items() if not k.startswith("_")}
    return json.dumps(clean, sort_keys=True, separators=(",", ":")).encode("utf-8")

def artefact_hash(artefact: dict) -> bytes:
    return Web3.keccak(canonical_bytes(artefact))        # 32-byte keccak256

def consent_id(artefact_hash_b: bytes, nonce: int) -> bytes:
    """nonce-based id: hash(fingerprint || nonce) so two consents never collide."""
    return Web3.keccak(artefact_hash_b + nonce.to_bytes(32, "big"))

def _expiry_unix(artefact: dict) -> int:
    cd = artefact.get("ConsentDetail", artefact)
    exp = cd.get("consentExpiry") or artefact.get("consentExpiry")
    if not exp:
        return int(time.time()) + 30 * 86400
    return int(datetime.fromisoformat(exp.replace("Z", "+00:00")).replace(tzinfo=timezone.utc).timestamp())

def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--artefact", required=True)
    ap.add_argument("--nonce", type=int, default=1)
    args = ap.parse_args()

    art = json.loads(Path(args.artefact).read_text(encoding="utf-8"))
    h = artefact_hash(art)
    cid = consent_id(h, args.nonce)
    expiry = _expiry_unix(art)

    w3, acct, c = get_web3(), None, None
    acct = get_account(w3); c = get_contract(w3)
    send(w3, acct, c.functions.createConsent(cid, h, expiry, args.nonce))
    send(w3, acct, c.functions.grantConsent(cid))
    print(f"registered consentId=0x{cid.hex()}  hash=0x{h.hex()}  expiry={expiry}")
    print(f"audit link: https://sepolia.etherscan.io/address/{c.address}")

def _selfcheck() -> None:
    """Hashing must be deterministic and tamper-sensitive (no chain needed)."""
    a = {"ConsentDetail": {"Frequency": {"unit": "MONTH", "value": 5}}, "_note": "ignored"}
    b = {"ConsentDetail": {"Frequency": {"value": 5, "unit": "MONTH"}}}          # same facts, keys reordered
    assert artefact_hash(a) == artefact_hash(b), "canonicalization must ignore key order"
    tampered = {"ConsentDetail": {"Frequency": {"unit": "MONTH", "value": 6}}}   # one value changed
    assert artefact_hash(a) != artefact_hash(tampered), "any change must change the hash"
    print("selfcheck OK")

if __name__ == "__main__":
    import sys
    (_selfcheck if "--selfcheck" in sys.argv else main)()
```

Run the offline check first (no chain, no gas), then the real thing:
```bash
python -m consentledger.chain.register_consent --selfcheck
python -m consentledger.chain.register_consent --artefact data/aa/consent_artefacts/real_onetime_loan_application.json
```

## 9. THE MAIN CONTRIBUTION — the security tests: `contracts/test/test_registry.py`

This is what makes it a *project*, not a toy. Put automated tests here that prove the tamper-evidence.
They run against your deployed Sepolia contract (small test-ETH cost) via web3.py.

```python
# contracts/test/test_registry.py
"""Adversarial + round-trip tests against the deployed ConsentRegistry (Sepolia).

Run:  python contracts/test/test_registry.py
"""
import time
from web3 import Web3
from consentledger.chain.web3_client import get_web3, get_account, get_contract, send
from consentledger.chain.register_consent import artefact_hash, consent_id

def run():
    art = {"ConsentDetail": {"Frequency": {"unit": "DAY", "value": 1}, "fetchType": "ONETIME"}}
    h = artefact_hash(art)
    nonce = int(time.time())              # unique each run so ids don't clash
    cid = consent_id(h, nonce)
    expiry = int(time.time()) + 3600

    w3 = get_web3(); acct = get_account(w3); c = get_contract(w3)
    send(w3, acct, c.functions.createConsent(cid, h, expiry, nonce))
    send(w3, acct, c.functions.grantConsent(cid))

    # 1. ROUND-TRIP: the exact hash on a live consent must verify TRUE (state-changing path).
    r = send(w3, acct, c.functions.recordAccess(cid, h))
    ok = c.functions.isValid(cid, h).call()
    assert ok is True, "genuine consent should verify"

    # 2. ADVERSARIAL / TAMPER: a changed artefact -> different hash -> must verify FALSE.
    tampered = artefact_hash({"ConsentDetail": {"Frequency": {"unit": "DAY", "value": 2}, "fetchType": "ONETIME"}})
    assert c.functions.isValid(cid, tampered).call() is False, "tampered artefact must fail"

    # 3. REVOCATION: after revoke, even the genuine hash must verify FALSE.
    send(w3, acct, c.functions.revokeConsent(cid))
    assert c.functions.isValid(cid, h).call() is False, "revoked consent must fail"

    print("ALL TESTS PASSED: round-trip OK, tamper rejected, revocation enforced.")

if __name__ == "__main__":
    run()
```

> **Expiry test (optional):** set `expiry = now + 60`, verify TRUE, `time.sleep(70)`, verify FALSE —
> proves lazy expiry. Skip on Sepolia if you don't want to wait; note it as a local-chain test instead.

from consentledger.chain.web3_client import get_web3, get_contract

## 14. If you get stuck / common issues

- **`cannot reach Sepolia RPC`** → check `SEPOLIA_RPC_URL` in `.env`; free Alchemy/Infura keys work.
- **`insufficient funds for gas`** → your test wallet is empty; get more from a Sepolia faucet.
- **`.raw_transaction` attribute error** → you're on web3 v5 syntax; this repo pins **v6** (use
  `signed.raw_transaction`, `w3.eth.send_raw_transaction`). Confirm `pip show web3` is 6.x.
- **`consent exists` revert** → you reused a `consentId`; bump `--nonce` (the tests use `time.time()`).
- **Transactions are slow** → Sepolia can take 15–60s per block; `wait_for_transaction_receipt` handles it.
- **Remix won't deploy** → make sure MetaMask is unlocked, on Sepolia, and "Injected Provider" is selected.
